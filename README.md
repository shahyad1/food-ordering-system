# Food Ordering System (Rust)

A console-based food-ordering system inspired by online food delivery platforms. The source models users, restaurants, menu items, and orders, with JSON-based persistence.

## Concepts and technologies
- Rust structs and serialization with Serde
- Restaurant menus and order data models
- JSON file persistence
- Timestamps with Chrono

## Run
Requires the Rust toolchain (Cargo).

```bash
cargo run
```

The application reads and writes JSON data files in its working directory. Review any generated data before committing it.

## Language
Rust
